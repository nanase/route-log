# 決定事項と未決事項

主な決定を 1 行ずつ並べます。理由と経緯は、それぞれの文書の節にあります。決定や調べて分かったことが出たら、ここと該当する文書の両方を直します。

## 決定事項

- ドラレコのファイル名形式：DJI Action 4、DJI_YYYYMMDDhhmmss_NNNN_D.mp4（JST）
- 分割ファイルの時刻：各ファイルのファイル名時刻は、そのファイルの録画開始時刻（確認済み）
- 都道府県道：国道マップで扱い済み
- Cloudflare の設定：wrangler で管理する
- 字幕の文言：路線は標識画像で表示するためテンプレートは不要。通過時刻が分かれば足りる
- 判定用データの形式：FlatGeobuf
- 道の駅データの出典：OSM。正確さは現時点では求めない
- 政令市の区の境：イベントにする
- フロントエンドの枠組み：Svelte 5
- パッケージ管理：bun
- 時刻の精度：1 分以内のずれは無視する。走行ごとの補正値で足りる
- 動画再生：WebView2 での直接再生（マイルストーン 1 で検証済み）
- Rust のビルド：dev プロファイルのデバッグ情報を削り、`target/` の肥大を抑える
- ffmpeg：mise の `conda:ffmpeg` で入れる。ffprobe と `h264_nvenc` を含む
- ローカルの保存：走行 1 つを JSON ファイル 1 つに書く
- 地図のライブラリ：MapLibre GL JS 5.24.0
- 判定用データの書き出し：ルートログのリポジトリに置く。国道マップは読むだけで、手を入れない
- N03 の簡略化：境を共有したまま、約 10 m のずれまで許す
- 時計の補正値を後から変えたとき：動画で確定した時刻は一緒に動かし、手で入れた時刻は動かさない
- Access の JWT 検証：純粋な Rust（`rsa` crate）で書く。サービストークンは `common_name` を持ち主として読む。本物のサービストークンで通ることを確認した
- API のホスト名：`routelog.nanase.cc`。デプロイは、いまは手元から `wrangler deploy` で行う
- 同期のしかた：保存のあとと起動のときに、自動で行う。人に聞くのは、両方で変わった走行をどちらで揃えるかだけ
- 走行の削除：クラウドからも消す。クラウドから消せないときは、手元の記録も消さない
- 字幕にするかどうか：時刻の状態とは別に持つ。字幕なしでも、確定した時刻は基準になる
- 経由地の通過時刻：時刻入力の画面で、地図の経由地の丸を押して確定する。イベントは、押したときに作る
- 名前の無い橋：イベントにしない。公称の名前が付けば残す
- 橋・トンネルの公称の長さ：国土交通省のデータベース（全国Q地図のタイル）の施設を対応づけ、「犬戻トンネル 737m」の形で一覧とマーカーに出す。橋は 100 m 以上、トンネルはすべて字幕にする
- 長い停車：録画停止を人が選んで停車にする。停車の間は進んでいないものとして推定する
- Worker のイベントの扱い：中身を見ずに往復させる。イベントの種類を足しても、Worker を入れ替えなくてよい
- 窓を閉じるとき：保存を待っている編集を書き終えてから閉じる
- クラウドへの書き込み：変わった行だけを書き、推定した時刻は送らない
- 概略図の動画：アプリで書き出す。背景は国土地理院の写真で、出典を右下に入れる。範囲はパートか経由地で選ぶ
- パートの概略図の動画：全部のパートを合わせた経路を見せてから、このパートへ寄る。他のパートは寄るにつれて薄くし、始点と終点の印はこのパートの両端に置く
- Resolve への受け渡し：FCPXML 1.10 とマーカーの EDL を書き出し、人が読み込む。Resolve のスクリプトは使わない（21.1 から Studio だけの機能）
- Resolve のプロジェクト：59.94 fps のドロップフレーム、3840×2160、データレベルは既定のビデオ
- マーカーの位置：通った時刻より、種類ごとに決めた長さ（既定 2 秒）だけ前に置く
- 停車の候補：音と映像の動きを組み合わせて見分ける。採るかは人がアプリで決める
- 国道の交差点：関わる国道をすべて並べた名前の `road` を、交差点の位置に出す。走らない国道は「（分岐）」、国道を離れるときは「（離脱）」を付ける
- パートの保存先：走行のデータに入れ、クラウドへも送る。パートは経由地で決めるので、動画ではなく経路に属する
- パートの端：経由地に ID を足し、ID で指す。端の経由地を消したら、範囲が縮む向きに付け替える
- パートの録画の長さ：両端の経由地の推定時刻の間で、録画のある時間から停車を引く。5 時間を超えたら印を付ける
