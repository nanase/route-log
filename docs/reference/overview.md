# 目的と範囲

ルートログは、バイクの走行経路と時刻を手動で記録し、ドラレコ動画に入れる字幕の候補とタイミングを自動で出すデスクトップアプリです。GPS ログがない動画（過去の動画を含む）でも、経路と少数の時刻を入力すれば字幕データを作れることを目指します。

## 背景

- ドラレコ動画を旅のログとして YouTube に投稿している
  - コメンタリーは入れず、字幕で出発時刻・出発場所、国道・都道府県道、市区町村・都道府県の境、橋、トンネル、道の駅を表示する
  - 国道・都道府県道は文字ではなく、重用区間を考慮した標識画像で表示することが多い
- 現状は地図を見ながら字幕の内容とタイミングを手作業で決めており、ここに最も時間がかかっている
- ドラレコ（DJI Action 4、H.265）に GPS はなく、過去の動画にも位置情報はない
- 車両は 125cc のため高速道路・自動車専用道路は走らない。走るのは国道・都道府県道・市町村道のみ

## MVP の範囲

1. 動画フォルダを読み込み、ファイル名と長さから実時刻のタイムラインを作る
2. 地図上で経路を入力・修正する（経由地の直線結び＋国道・都道府県道への吸着）
3. 経路から境界・道路・橋・トンネルのイベントを抽出し、時刻を推定する
4. 動画を見ながらキー操作でイベント時刻を確定する
5. イベントの通過時刻一覧（CSV）を書き出す

## MVP 後

- Cloudflare へのログ保存
  - 作った。[クラウド API と同期](cloud.md) にある
- DaVinci Resolve 連携（パート、停車の検出、タイムラインとマーカーの書き出し）
  - 作った。[Resolve 連携](resolve.md) にある
- 冒頭の経路映像の生成
  - アプリで書き出す概略図の動画として作った。[出力](output.md#概略図の動画) にある
- 走行ログの共有（閲覧専用ページ）
- 自作 GPS ロガーのログ取り込み

## 対象外

- 動画ファイルの保存・アップロード
  - 編集後に元データは削除するため
- 動画の編集
  - 停車を抜いたタイムラインは書き出すが、Resolve を操作して切ることはしない
