# 画面と操作

メイン画面は地図・動画・イベント一覧・タイムラインの 4 領域で構成し、動画の再生位置と地図上の現在位置を連動させます。

| 領域 | 内容 |
| --- | --- |
| 地図（左） | 経路、経由地、イベント位置のマーカー、推定現在位置 |
| 動画（右上） | 仮想タイムライン上の動画再生。実時刻と次のイベントを重ねて表示 |
| イベント一覧（右下） | kind・label・推定／確定時刻・status。ラベルの編集、非表示、手動追加 |
| タイムライン（下） | 動画ファイルの範囲、録画停止区間、イベントを実時刻軸に並べる |

## 経路入力の操作

- 地図クリックで経由地を追加、ドラッグで移動、右クリックで削除
- 経路の線の上をクリックすると、そこに経由地を足して区間を 2 つに分ける。分けた区間は元の結び方を受け継ぐ
- 線の中間をドラッグすると頂点を追加（手修正。その区間は segment_mode = manual）
  - 線の区切りごとに、まん中に小さな丸を出す。それをドラッグすると頂点になる
  - 画面上で 48 px より短い区切りには、丸を出さない
  - 頂点もドラッグで移動、右クリックで削除
- 区間ごとに結び方を切り替える：straight（直線）／snap（吸着）
  - 操作は [吸着の操作](geo.md#吸着の操作) にある
  - 経由地をクリックして選ぶと、そばに結び方の切り替えと削除のボタンが出る
- 経路の編集は、取り消しとやり直しができる
  - 走行を切り替えると、取り消せる編集は無くなる
- 操作は、した順に 1 つずつ経路に入れる。点を道へ寄せるのと、走行を作るのを待つ間に、次の操作や保存の応答が入るためである
  - 地図は、変えた後の経路ではなく「経路を受け取って経路を返す操作」を渡す。順番が来たときの経路に当てるので、古い経路から作った結果で上書きしない
  - 前の操作が経路に入るまで、次の操作を始めない。続けて押した点は、押した順に並ぶ。取り消しとやり直しも、同じ列に並べる
  - 経由地や区間は番号で指す。待つ間に、その番号の相手が別の所へ動いていたら、その操作は捨てる
  - 丸を押している間と、離した位置が経路に入るまでの間は、丸を置き直さない。保存の応答で丸を作り直すと、つかんでいる丸が消えて、ドラッグが途切れる
  - 保存は 1 つずつ行う。前の保存が済むまで、次を書かない
- 経由地またはイベントに時刻を入力すると、時刻推定の基準になる

## 画面のデザイン

2026-10-13 に決め、実装しました。

使ってみたところ、画面が必要最低限すぎて使いづらかったため、デザインを 3 案作って「地図が主役」の案に決めました。

- 配色はライト。地は白と淡い灰、操作の主色は標識の青、経路は赤、確定は緑
- 経路を入力するときは、地図を画面いっぱいに置き、上の帯・道具・一覧・操作の手がかりを浮かせる
- 時刻を入力するときは、地図が左、動画が右上、イベントの一覧が右下、タイムラインが下に全幅
- イベントの状態は、色だけでなく形でも分ける。確定は塗りの丸、推定は破線の輪、字幕なしは斜線の輪と取り消し線
  - 字幕なしで時刻を確定してあるものは、輪と斜線を確定の緑にする
- イベントの種類は、漢字 1 字の札で出す（発・着・路・県・市・橋・ト・駅・点・停・手）
- 国道は逆三角、都道府県道は六角形の、青地に白数字のバッジで出す
- 道路データと判定データのフォルダ、時計の補正は「設定」にまとめる。動画フォルダは走行ごとに選ぶ
- 走行の切り替えは、上の帯の日付と題を押すと開く。削除もそこに置き、同期のダイアログは無くす
- 保存と同期の状態を、まとめて上の帯に 1 つ出し、エラーは赤い帯で残す
  - 当初は保存の状態だけを出し、同期は「同期」ボタンから人が行っていた。「保存されている」と「同期されている」が別々に見えて分かりにくかったので、同期を自動にして 1 つにまとめた
- 書体は BIZ UD ゴシックを同梱する

## いまの画面

上の帯の「経路入力」「時刻入力」で、2 つの画面を切り替えます。地図は同じものを使い続け、動画は読み込んだままにします。

画面の呼び名は、使ってみての指摘で 2026-10-14 に直しました。「経路を入れる」を「経路入力」、「時刻を確定する」を「時刻入力」、「次に確定する」を「次の候補」、「いまの位置で確定」を「時刻を確定」、「字幕にしない」を「字幕なし」にしています。

2026-10-25 にも、使ってみての指摘で呼び名を直しました。

- 用語：「経由点」を「経由地」、「回」を「パート」にした。パートは、Resolve でソースを包むパートのタイムライン 1 本ぶんに当たる。名前が空のパートは「第 n 回」ではなく「パート n」と呼ぶ
- 上の帯：「停車を探す」を「停車位置探索」、「概略図の動画」を「概略図生成」、「CSV を書き出す」を「CSV エクスポート」にした
- 地図：「現在位置を追う」を「現在位置に追従」、「点の結び方」を「連結方法」、「経路の全体を表示」を「全経路表示」にした
- 操作の手がかりは「操作方法」と呼ぶ。開閉は「出し入れ」の字ではなく、山形の印で示す
- 「選んでいる」を「選択中」、「外した」動画を「除外」、「抽出し直す」を「再抽出」にした
- 概略図生成の欄は「全経路の時間」「ズーム時間」「ストップ時間」、ボタンは「生成」にした
- 設定は「選び直す」を「再選択」、「変える」を「変更」にした
- 説明の文のうち、無くても分かるものは消した。経路入力のイベントの欄の字幕なしは、印だけで示す
- ツールチップと、そのとき気づいた文言（「足す」→「追加」、「やめる」→「中止」、停車の候補の「採る／外す」→「採用／除外」、「確定を外す」→「確定を解除」、「停車おわり」→「停車終了」など）は、修正案を並べたページで利用者が判定した
- 2 度目の見直しで、読点・説明文・動詞の終止形の残る文言 96 件を直した。画面には「Resolve」と「クラウド」を出さない。クラウドは「同期先」と呼び、Resolve は「エクスポート」の先として名前を出さない（EDL・FCPXML のような形式の名前は出してよい）。開発の都合（Worker が古いなど）も画面に出さない

| 部品 | 出る画面 | 内容 |
| --- | --- | --- |
| 上の帯 | 両方 | 開いている走行、画面の切り替え、保存と同期の状態、停車位置探索、概略図生成、CSV エクスポート、設定 |
| 知らせ | 両方 | エラーと注意は上の帯の下に帯で残す。Resolve への書き出しを終えたことも、読み込み方を添えて帯で残す。ほかのできたことと、同期できなかったことは、右下に数秒だけ出す |
| 地図の道具 | 経路 | 取り消しとやり直し、足す区間の連結方法、全経路表示 |
| 地図の表示 | 両方 | 拡大・縮小のボタンの下のボタンで開く板。背景地図、道路の線の表示、凡例 |
| 操作方法 | 経路 | マウスの操作の一覧。? キーで開閉し、開閉は次の起動にも残す。閉じたときの幅を測り、地図の縮尺をその右へ逃がす |
| 経由地・パート・イベントの一覧 | 経路 | 経由地ごとの距離と結び方、パートの範囲と録画の長さ、経路から出たイベント |
| 動画 | 時刻 | 再生、実時刻、再生の操作のボタン。動画の上には、ブラウザの操作の帯も出す |
| 次のイベントの案内 | 時刻 | 次の候補、推定時刻、確定の操作のボタン |
| イベントの一覧 | 時刻 | 状態・時刻・距離・種類・名前。状態、種類、名前で絞り込める。いくつか選んで、字幕に出すかどうかをまとめて切り替えられる |
| タイムライン | 時刻 | 動画ファイルの範囲、録画停止、停車の候補、イベントの印、再生位置。広げたり縮めたりできる |

- 走行は、選んだ動画フォルダの中の、その日付の動画と結び付く。動画が無くても、経路は記録できる
- 起動すると、前に開いていた走行を開く。その走行がもう無ければ、いちばん新しい走行を開く
  - 動画フォルダを読むのを待たずに開く
- 時刻入力の画面では、地図と右の列の境目をドラッグして、列の幅を変えられる。動画は列の幅いっぱいに出るので、一緒に大きくなる
  - 幅は 420 px から。地図に 540 px、一覧に数行の高さが残る所までしか広げられない
  - 幅は次の起動でも使う。境目をダブルクリックすると、元の 520 px に戻る
- 動画が無い走行でも、時刻入力の画面で、一覧の行を押して時刻を手で入れ、推定を見て、CSV を書き出せる
  - 動画とタイムラインの場所に、動画が無いことと、時刻は一覧で手で入れられることを出す
  - 動画に頼る操作（Enter、A、再生のキー）は、押しても何も起きない
- 窓を閉じるときは、保存を待っている編集を手元に書き終えてから閉じる
  - 手元への保存は、同期とは別に行う。同期できないときも、編集は手元に保存されている
- タイムラインの録画停止を右クリックすると、その間を停車にする板が出る。停車にした間は「停車」と出る
- タイムラインの動画の帯を右クリックすると、その動画を走行から外す板が出る
  - 外した動画は、破線の薄い帯で残る。押すと、戻す板が出る
  - すべて外すと、動画が無い走行と同じ画面になる。薄い帯は残るので、戻せる
- 上の帯の「停車位置探索」で、走行に使う動画から、信号待ちを含む停車の候補を探す（[停車を音と映像の動きで見分ける](resolve.md#停車を音と映像の動きで見分ける)）
  - 探してある動画は飛ばす。走行から外した動画は探さない
  - 裏で動くので、探している間も時刻入力を続けられる。ボタンは「中止」と進み具合に変わり、押すとやめる。探し終えた動画の候補は残る
  - 探し終えたら、候補の数を知らせる
- 停車の候補は、タイムラインの動画の帯に重ねた橙の帯で出す。帯には「停」と長さを書く
  - 帯を押すと、ほかの所と同じく再生位置がそこへ動く。映像で確かめられる
  - 帯を右クリックすると、採るか外すかを選ぶ板が出る（画面では「採用」「除外」）。既定は採るで、書き出しで抜く
  - 外した候補は、破線の枠だけの帯で残る。右クリックで、また採れる
  - 候補の始まりと終わりは、アプリでは直さない
- 走行のファイルは、最初に編集したときに作る
- 走行の切り替えは、上の帯の日付と題を押すと開く板で行う
  - 走行を開いても、作っても、板は閉じない。続けて題やラベル、動画フォルダを入れたり、ほかの走行を開いたりできる。板の外を押すか Esc で閉じる（2026-10-26。以前は開くと閉じていた）
  - 日付を入れて新しく作る。開いている走行の題を直す
  - 走行の記録を消す。消す前にその場で確かめる。動画のファイルは消さない
    - 同期を設定していれば、クラウドからも消える。確かめる文言に、そのことを書く
  - 走行ごとに、同期の状態を小さく出す。送る・受け取るボタンは無い
  - 両方で変わった走行だけは、どちらを残すかをこの板で選ぶ
  - すべて同期できているときは「すべての走行ログが同期済み」と出す

## 設定・上の帯・地図

- 設定のダイアログに、道路データと判定データのフォルダ、時計の補正、マーカーの前倒し、クラウド同期の接続先をまとめる
  - 道路の線は、国道マップの配信データ（PMTiles）のフォルダを選んで読む。選ばなければ重ねない
  - 判定用データのフォルダを選ぶと、経路を保存するたびにイベントを抽出し、一覧と地図の点に出す
- 上の帯には、保存と同期の状態をまとめて 1 つ出す。「同期」ボタンは無い
  - 同期を設定していれば、保存中…、同期中…、同期済み、未同期、両方で変更のどれかを出す
  - 同期を設定していなければ、保存中…か保存済みを出す
  - 手元に保存できなかったときは、どちらでも「保存できません」と、やり直すボタンを出す
  - それぞれの意味と決め方は、[アプリからの同期](cloud.md#アプリからの同期) にある
- 背景地図は、地理院タイルの淡色・標準・写真から選ぶ。時刻入力の画面でも選べるよう、拡大・縮小の下の「地図の表示」の板に、道路の線の表示と凡例と一緒に置く。板は押したときだけ開き、外を押すか Esc で閉じる（2026-10-25）
- 時間のかかる操作は、動いている間、ボタンや状態の字の横に回る輪を出す。再抽出、パートのエクスポート、停車位置探索（進み具合の % と一緒に）、概略図生成の写真の読み込みと生成、設定のフォルダの読み込み、保存と同期である（2026-10-25）
- 経路は、道に沿わせた区間を実線、それ以外を破線で描く
- イベントの一覧の行を押すと、地図がその位置へ動き、名前を添えた吹き出しが出る
- 時刻入力の画面では、経路は見るだけになる。地図は現在位置に追従する
  - 経由地の丸は小さく出す。通過時刻を確定してある経由地は、緑にする
- 地図は MapLibre GL JS 5.24.0 を使う。6 系は ESM 専用になったので、上げるのは後にする

## 走行ごとの動画フォルダ

2026-10-26 に決めました。

動画は走行ごとに別のフォルダへ置くことが多くあります。以前はアプリで動画フォルダを 1 つだけ覚えていたので、別のフォルダの走行を開くたびに選び直す必要がありました。選び直すと、前のフォルダの走行は「動画なし」になりました。いまは、走行（日付）ごとに動画フォルダを覚えます。

- 動画フォルダは、走行の切り替えの板の、開いている走行の行で選ぶ。「動画フォルダ」の枠に、覚えたフォルダと本数を並べる
  - 「フォルダを追加」で足す。足すと、すぐに読む。選んだフォルダにその日付の動画が無ければ、覚えずに「選択されたフォルダには YYYY-MM-DD の動画がありません」と出す
  - 1 つの走行に 2 つ以上のフォルダを足せる。同じ名前の動画は、先に足したフォルダのほうを使う
  - 行の回る矢印で読み直す。× で外す。外す前にその場で「このフォルダを除外しますか」と確かめる。動画のファイルは消さない
  - 選び直すボタンは置かない。別のフォルダにするときは、足してから前のフォルダを外す
- 動画の欄の「動画フォルダを選択」も、開いている走行にフォルダを足す。設定は開かない
- 走行を開くたびに、その走行が覚えたフォルダだけを読み直す。起動のときに、すべての動画を読むことはしない
- 覚えたフォルダが見つからないとき（ディスクを外した、消した、移した）
  - 動画フォルダの枠では、その行に警告の印を付け、本数の代わりに「見つかりません」と出す
  - 動画が 1 本も無ければ、上の帯に「動画フォルダなし」を注意の色で出す。走行の一覧の行と動画の欄には「動画が見つかりません」と出し、動画の欄に場所と「再読み込み」「動画フォルダを選択」を出す
  - ディスクを差し直したかは見張らない。人が「再読み込み」を押す
- 走行の一覧には、記録のある走行だけを並べる。以前は、動画フォルダの中の日付を、記録が無くても並べていた
  - 新しい走行は、日付を入れて作ってから、動画フォルダを選ぶ
- 以前の版で覚えていた動画フォルダは、最初の起動のときに 1 度だけ読み、中の動画の日付ごとの動画フォルダとして覚え直す。覚え直したら、`config.json` の `video_dir` を消す。フォルダが見つからなければ、次の起動でまた試す
- 画面の形と文言は、見本の上で利用者のコメントを受けて決めた。一覧の上に「動画フォルダを開く」を置く案と、フォルダの行に「再選択」を置く案は、「フォルダを追加」と役目が重なるので外した

## 走行のラベル

2026-10-19 に決めました。

走行ログは、動画を作らずに、日時と経路を残すためにも使います。「投稿済」のような目印を付けて、一覧で見分け、絞り込めるようにします。どんなラベルを使うかは決まっておらず、使わないこともあります。

- 前もって定義しない。走行の切り替えの板で、開いている走行の題の下の欄に打ち、Enter で付ける
  - 前に使ったラベルを、付いている走行の数と一緒に候補に出す。候補に無い名前は、新しいラベルとして付ける
  - 前後の空白を除き、続く空白を 1 つにする。同じ名前は 2 度付けない
  - 札の × で外す。欄が空のときの Backspace は、最後の札を外す
  - 日本語の変換を確定する Enter では付けない
- 一覧では、題の横に札を出す。色は名前から 8 色のどれかに決まり、同じ名前はどの PC でも同じ色になる
  - 状態の色（緑・黄・赤）とまぎれない色相にする。同期の状態の丸い札と見分けるため、角を小さくする
  - 札の見た目と置き場所は、見本で 2 案を比べて決めた。下の行に点の付いた札を出す案もあった
- 一覧の上に、どれかの走行に付いているラベルを、多く使っている順に並べる。ラベルが 1 つも無ければ出さない
  - 押すたびに、付いている走行だけ（青）、付いていない走行だけ（赤）、外す、と変わる。2 つ以上選べば、どれにも当てはまる走行だけを出す
  - 付いていない走行だけのときは、赤く塗った上で名前に線を引く。線だけでは分かりにくかった
  - 絞り込みは、板を閉じても覚えておく。アプリを閉じれば忘れる
- 走行（Ride）の `labels` に、付けた順の文字列の配列で持つ。この項目が無い頃の記録は、空として読む
- クラウドでは、`rides` の `labels` 列に JSON で持つ。ラベルで探すことは Worker ではしないので、表に分けない
  - 古い Worker は、ラベルを知らずに捨てる。マイグレーション 0002 を当てて Worker を入れ替えるまで、ラベルは同期されない

## パート

2026-10-24 に決めました。

YouTube に上げる 1 本ぶんの範囲を「パート」と呼びます。Resolve へ書き出すソースのタイムラインと、概略図の動画は、パートごとに作ります。

- 経路入力の右の一覧で、経由地とイベントの間に「パート」の欄を置く
  - 「追加」で、経路の全体を範囲にしたパートができる。経由地が 2 つ無ければ足せない
  - パートごとに、名前と、始まりと終わりの経由地を選ぶ。経由地は、番号と名前（出発・到着・経由地のイベントの名前）で出す
  - 名前は付けなくてよい。空なら「パート n」と並びの番号で呼ぶ
  - ごみ箱のボタンで消す
  - その隣の書き出しのボタンで、Resolve へ書き出す（[Resolve へ書き出す](resolve.md#resolve-へ書き出す)）
  - パートの欄は、経由地やイベントが多くても縮めない。高さはパート 3 つぶん（240 px）までで、それを超えたら欄の中で送る
    - 当初は、ほかの一覧と同じく縮めてよいことにしていた。経由地 84 個・イベント 163 件の走行では、中身の多い一覧と同じ割合で縮み、1 行ほどになって押せなかった（2026-10-24）
  - パートの編集は、経路の編集と同じ列に並べ、取り消せる。経由地を消してパートの端が付け替わっても、取り消せば戻る
- 前後のパートで範囲が重なってもよい
- パートは、始まりと終わりの経由地を ID で指す
  - 経由地を足す・動かす・消すをしても、ほかの経由地を指したままになる
  - 経由地のイベントのように位置で指す案もあった。往復の走行で同じ場所にある始点と終点を取り違え、経由地を 30 m より遠くへ動かすと外れるので、採らなかった
  - 経由地の ID は UUIDv7。ID の無い頃の走行には、読み込むときに振る。次の保存で書かれる
- 端の経由地を消したら、内側の経由地へ付け替える。始まりなら次の、終わりなら前の経由地にする
  - 範囲が縮む向きにするので、隣のパートへはみ出さない。隣り合うパートの境の経由地を消すと、2 つのパートの間が空く
  - 付け替えて始まりと終わりが同じか逆になったパートは、消さずに残す。欄を赤くし、「終わりは、始まりより後の経由地にします」と出す
- パートごとに録画の長さを出し、5 時間を超えたら警告の印を付ける。止めはしない
  - Resolve のソースのタイムラインを、5 時間までにするためである
  - 長さは、両端の経由地を通った推定時刻の間で、録画のある時間から停車（`stop` のイベント）を引いて数える。走行から外した動画の時間は、録画の無い時間になる
  - どちらかの時刻が推定できなければ「録画 不明」、動画が無ければ「動画なし」と出す
  - 停車の検出で出す候補は引かない。正確な長さは、書き出したときに知らせる
  - 推定時刻は保存のたびに求め直す。経路を変えた直後は、保存が済むまで長さが少しずれる
  - 距離は Rust 側と画面で計算の順が違い、末尾の桁がずれる。時刻を推定するとき、基準と 1 mm 以内の位置は基準と同じ所とみなす。そうしないと、終わりの経由地が到着の基準より先に出て、時刻を推定できなかった
- 書き出しと概略図の動画は、routelog-core の `RideDocument::extent`（端の経由地の番号・距離・推定時刻）と `recorded_ms`（録画の長さ）を使う
- 走行の `episodes` に、`id`・`title`・`from`・`to`（端の経由地の ID）を持つ。この項目が無い頃の記録は、空として読む
- クラウドでは、`rides` の `episodes` 列に JSON で持つ。走行あたり数件なので、表に分けない。Worker はイベントと同じく中身を見ずに往復させる
  - 経由地の ID は、`waypoints` の `id` 列に持つ。ID を持たない古いアプリが送った経由地は NULL で持ち、空の ID で返す
  - どちらもマイグレーション 0003 で足す。古い Worker は、パートと経由地の ID を知らずに捨てる。0003 を当てて Worker を入れ替えるまで、パートは同期されない

## 時刻入力の操作

- 動画を再生すると、推定時刻から地図上の現在位置と「次のイベント」を表示する
- 看板やトンネル入口を通過した瞬間に確定キー（Enter）を押すと、次のイベントの時刻がその再生位置の実時刻で確定する
- 確定後、後続の推定時刻が再計算される
- 「次のイベント」の決め方
  - 一覧で選んだイベント、または N / P で移った先のイベント
  - 選んでいなければ、推定時刻がいまより後の最初のイベント。推定の無いうちは、位置の順で最初の未確定のイベント
  - Enter で確定すると、その後ろの未確定のイベントへ進む
- 一覧で選んだイベントは、名前・通過時刻・字幕に出すかどうかを直せる。時刻を手で入れると、その時刻で確定する
  - 直す欄は、行を押すと開き、もう一度押すと閉じる
  - 字幕なしにしても、確定した時刻は消えない
- 字幕なしのイベントは、次の候補に自動では出さない。一覧やタイムラインで選べば、同じように確定できる
- 経由地を通った時刻を入れるには、地図の経由地の丸を押す。その経由地が次の候補になり、Enter で確定する
  - 経由地のイベントは、押したときに初めて作る。経由地のすべてを一覧に並べると、一覧が埋まるためである
  - 字幕なしで作る。一覧で、名前を付けて字幕ありに変えられる。要らなければ消せる
  - 作ったイベントは、初めから一覧の位置の順の所に入れる。末尾に足すと、保存の応答で並び直すまでの間に一覧が最後まで送られ、戻す手間がかかった。手動のイベントと停車も同じにしている
  - 押すのは、動画がそこを通るのを見たときである。一覧の行を押したときと違って、動画は動かさない
  - 始まりと終わりの経由地を押すと、出発と到着が次の候補になる
- 一覧の行の左のチェックでいくつか選ぶと、字幕あり・字幕なしをまとめて切り替えられる
  - Shift を押しながらチェックすると、前にチェックした行からそこまでを選ぶ
  - 絞り込みの欄の左のチェックで、出している行をすべて選ぶ。種類で絞ってから使うと、橋だけをまとめて字幕なしにできる
- 動画の上には、ブラウザの操作の帯（再生、シーク、音量、全画面）も出す
  - 音量は覚えて、次の起動でも使う。初めは 50% にする。消音は覚えない。次の起動で音が出ないと、わけに気づきにくい
  - 帯のシークが届くのは、いま読んでいるファイルの中だけである。ファイルをまたぐには、タイムラインを使う
  - 帯で再生・停止しても、倍率の表示が合う
- 短い橋など、抽出が非表示にしたイベントを人が表示に変えたら、抽出し直しても表示のまま残る。名前を直した場合も残る

## キー操作

| キー | 動作 |
| --- | --- |
| Space | 再生／一時停止 |
| J / K / L | 逆再生・停止・再生（Resolve に合わせる）。L を続けて押すと 2 倍、3 倍、4 倍。逆再生は 0.3 秒ごとのシークで代用し、J を続けて押すと速くなる |
| ← / → | 1 秒戻る／進む（Shift で 10 秒） |
| Enter | 次のイベントを現在位置で確定 |
| N / P | 次／前のイベントの推定時刻へ移動 |
| Backspace | 直前の確定を取り消す |
| A | 現在位置に custom イベントを追加 |
| S | 現在位置を停車の始まりにする。始まりだけを入れた停車があれば、その終わりにする |
| Ctrl+Z / Ctrl+Y | 経路の編集を取り消す／やり直す |
| ? | 操作方法を開閉する |
| Esc | 選んでいる経由地とイベントを外す。停車の場所を決めているなら、やめる。字を打つ欄では、欄を離れる |

- 再生と確定のキーは「時刻入力」の画面で、取り消しと ? は「経路入力」の画面で効く
- 字を打つ欄とダイアログの中では、キーは画面の操作にならない
- ボタンをマウスで押しても、キーの行き先はボタンに移さない。押したあとも Space と Enter が動画と確定に届く
